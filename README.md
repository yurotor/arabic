# ערבית מאפס – הכנה לבוחן

חומרי לימוד לבוחן בערבית של שכבת ח׳ (12.11).

- `index.html` – דף הסברים: אותיות, ניקוד, כינוי השייכות "שלי", תא מרבוטה ואוצר המילים.
- `arabic-practice.html` – דף תרגילים אינטראקטיבי עם משוב מיידי.

כל דף הוא קובץ HTML אחד. פותחים אותו בדפדפן, אין צורך בהתקנה.

האתר: https://yurotor.github.io/arabic/
